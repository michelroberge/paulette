# paulette

**Version:** 0.2.0  
**Author:** Michel Roberge

## How to Use

### Development

```sh
cd /home/paulette/repos/paulette/frontend && npm run dev
cd /home/paulette/repos/paulette/backend && go run main.go
```

### Build

```sh
cd /home/paulette/repos/paulette/frontend && npm run build
cd /home/paulette/repos/paulette/backend && go build -o paulette ./main.go
```

### Run

```sh
cd /home/paulette/repos/paulette/backend && ./paulette
```
