Product Vision: SaaS Dashboard

Problem Statement

Small business owners waste 3–5 hours per week switching between disconnected analytics tools, leading to missed insights and delayed decisions. There is no affordable, unified dashboard tailored to non-technical users.

Target Users

  • Non-technical founders at companies with 1–50 employees
  • Operations managers responsible for reporting
  • Freelancers tracking client project metrics

Core Value Proposition

A single dashboard aggregating revenue, traffic, and engagement metrics from popular SaaS tools, with AI-powered insight summaries delivered weekly.

Competitive Landscape

Existing solutions (Databox, Geckoboard, Klipfolio) target mid-market teams with complex setup. Our differentiation: zero-config onboarding via OAuth, opinionated default dashboards, and AI-generated weekly digests.

MVP Scope (v1.0)

  • Integrations: Stripe, Google Analytics, Mailchimp
  • Dashboard with 3 default widgets: Revenue, Traffic, Email Engagement
  • Weekly AI-generated insight email
  • OAuth-based onboarding (no manual API keys)

Architecture: SaaS Dashboard

System Overview

Monorepo using Turborepo with three packages: web (Next.js 14 app router), api (tRPC server), and integrations (background worker service).

Tech Stack

  • Frontend: Next.js 14, TypeScript, Tailwind CSS, Shadcn/UI
  • Backend: tRPC, Drizzle ORM, PostgreSQL 16
  • Auth: NextAuth.js with OAuth providers
  • Integrations: Bull MQ worker for Stripe/GA/Mailchimp sync
  • Infrastructure: Vercel (web), Railway (API + DB + worker)

Data Model

Core entities: User, Organization, Integration, MetricSnapshot, Dashboard, Widget.

Key Relations

  • User → belongs to Organization (many-to-one)
  • Organization → has many Integrations
  • Integration → generates MetricSnapshots (time-series)
  • Dashboard → contains ordered Widgets

API Design

tRPC router with namespaced procedures: dashboard.get, dashboard.update, integration.connect, integration.sync, metrics.query.

Security

  • OAuth tokens encrypted at rest (AES-256)
  • Row-level security via organization scoping
  • Rate limiting: 100 req/min per user
